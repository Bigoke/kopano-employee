# Kopano Employee (web app)

The Kopano Payroll employee app for iPhone and iPad: https://bigoke.github.io/kopano-employee/

Employees open the iPhone link from their invitation in Safari, tap Share > Add to Home Screen, and sign in from the
new icon. This repository only holds the published files; the source is `web/` and `android/www` in Kopano Payroll
(built with `web/build.sh`). It holds no passwords or company data.
